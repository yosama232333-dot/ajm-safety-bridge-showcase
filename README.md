# AJM Safety Bridge — Project Showcase

## English

AJM Safety Bridge is a bilingual website concept for an Egyptian industrial supplies and personal protective equipment company. It presents safety products in English and Arabic, with right-to-left support for Arabic readers.

### Highlights

- Responsive home page and product catalog
- Categories for helmets, high-visibility clothing, gloves, footwear, eye and respiratory protection, and fire systems
- Product catalog designed for local product imagery
- Separate administrative dashboard and API architecture

### Technology

- Website: React, TypeScript, TanStack Start, Vite, Tailwind CSS
- Admin/API: Next.js, TypeScript, Prisma, PostgreSQL

This public repository is an overview only. It does not include the project source code. The source remains in a private repository.

## العربية

- صفحة رئيسية وفهرس منتجات متجاوبان مع الأجهزة المختلفة
- تصنيفات لمعدات السلامة والوقاية الشخصية
- تصميم يدعم صور المنتجات محليًا
